## About

**AERO7 GRAM** is an independent project exploring what a modern Telegram desktop experience could look and feel like through the visual language of **Windows 7 Aero**.

The design direction focuses on translucent glass surfaces, subtle reflections, cool blue and mint-green colours, crisp typography and a familiar desktop atmosphere.

> The goal is not to recreate Windows 7 pixel by pixel. It is to bring its visual character into a clean, contemporary messaging experience.

## Design principles

- **Aero-inspired interface** — translucent layers, glass-like panels and soft highlights.
- **Blue + mint palette** — bright, calm shades inspired by the classic Aero aesthetic.
- **Desktop-first clarity** — conversations and essential controls should remain easy to use.
- **Modern foundations** — nostalgia in the visual language, not a compromise in usability.

## Project status

AERO7 GRAM is at an early stage. The repository and website currently establish the project's identity and design direction. Application implementation, supported platforms, installation instructions and release plans will be documented when they are confirmed.

No application build or working Telegram client is currently promised by this README.
