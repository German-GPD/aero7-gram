AERO7 GRAM — TEST BUILD

This archive contains an early Windows test build of the AERO7 GRAM desktop shell.

IMPORTANT
- This is an experimental test build, not a stable release.
- TDLib is not included. Telegram login, chats and message sending are unavailable.
- Building on GitHub's Windows runner does not prove compatibility with Windows 7 SP1.
- Test on a spare PC or virtual machine. Do not use it as your primary Telegram client.
- No installer is included. Extract the whole ZIP and run "AERO7 GRAM.exe".
- Keep all DLL files and the platforms folder beside the executable.

Please report crashes, missing DLL messages, visual glitches and your Windows version.
Project: https://github.com/German-GPD/aero7-gram


Installer note: the Windows test package is distributed as an Inno Setup installer. Default install path: C:\Program Files\German\G-Code-Team\Aero7Gram.
